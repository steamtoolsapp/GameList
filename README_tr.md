## 🚀 SteamTools Nasıl Kullanılır?

1. **Oyununuzu Bulun**: [SteamToolsApp.com](https://steamtoolsapp.com/tr) üzerinde oyun adını arayın veya Steam App ID girin.
2. **Paketi İndirin**: `{appId}_public.lua`, `key.vdf` ve kılavuzu almak için **ZIP İndir** butonuna tıklayın.
3. **Dosyaları Yerleştirin**: `.lua` ve `key.vdf` dosyalarını SteamTools kurulum dizinine kopyalayın.
4. **Yeniden Başlatın**: SteamTools ve Steam'i açın — oyun kütüphanenizde görünecektir.
