## 📖 项目简介

**GameList** 是驱动 **[SteamToolsApp.com](https://steamtoolsapp.com/zh)** 的核心开源游戏数据库。收录了热门 Steam 游戏的基础信息、Steam AppID、封面图谱及双语元数据。

配合 **[ManifestHub](https://github.com/steamtoolsapp/ManifestHub)** 清单仓库，可秒级一键在线生成经过验证的 `.lua` 注入脚本、`key.vdf` 解密密钥包及全量清单 ZIP 压缩包。

## 🚀 极速使用流程

1. **查找游戏**：在 **[SteamToolsApp.com](https://steamtoolsapp.com/zh)** 输入游戏名称或粘贴 Steam App ID；
2. **生成下载**：点击 **下载 ZIP 解锁全套包**，获取 `{appId}_public.lua`、`key.vdf` 及配置指南；
3. **放置文件**：将解压得到的 `.lua` 与 `key.vdf` 复制粘贴到您的 SteamTools 客户端安装目录下；
4. **启动同步**：启动 SteamTools / Steam，游戏即可成功入库并开始同步。

## 🔌 开发者 REST 开放接口

免 Token、免注册，直接通过标准 HTTP 接口调用元数据检索与清单生成：

### 1. 游戏联想与搜索
```bash
curl -s "https://steamtoolsapp.com/api/search?q=wukong" | jq
```

### 2. 自动化生成清单包
```bash
curl -s "https://steamtoolsapp.com/api/generate?appId=2358720" | jq
```
